## 🚀 Proyectos Destacados
### 📚 [Bookstore Management System](https://github.com/AlonsoPelaezFlores/BookStoreManagementSystem)
API REST para la gestión de una librería, con autenticación por roles (administrador, empleado y cliente). Cubre el ciclo completo de un backend real: seguridad, acceso a datos optimizado y pruebas.
 
- **Stack:** Java 17, Spring Boot, Spring Security, JWT, JPA/Hibernate, PostgreSQL
- **API:** 50+ endpoints REST para operaciones CRUD, con paginación y validaciones personalizadas
- **Seguridad:** autenticación y autorización basada en roles con Spring Security y JWT
- **Rendimiento:** resolví el problema N+1 con Entity Graph, reduciendo un 85% las peticiones a la base de datos
- **Calidad:** arquitectura en capas con principios SOLID y tests con JUnit y Mockito
### ⚡ [spring-rate-limit](https://github.com/AlonsoPelaezFlores/spring-rate-limit)
Librería de rate limiting para aplicaciones Spring, basada en el algoritmo token bucket. Se usa con una sola anotación, `@RateLimit`, sin tocar la lógica de negocio.
 
- **Stack:** Java 17, Spring AOP, AspectJ, Redis, Lua, Jedis, Maven, Docker
- **Cómo funciona:** un aspecto intercepta cada llamada y la comprueba contra un perfil de límites definido en un archivo de propiedades; las llamadas que lo superan se rechazan con una excepción
- **Límites:** globales o por clave, por ejemplo por usuario
- **Distribuido:** con Redis, el token bucket se ejecuta como un script Lua atómico para compartir el límite entre varias instancias sin condiciones de carrera; con una sola instancia funciona en memoria y sin configuración
- **Calidad:** almacenamiento intercambiable mediante una interfaz propia y tests con JUnit 5, incluida la concurrencia
